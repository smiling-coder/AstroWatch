UNDERSTANDING THE SCIENCE

Measure. Analyze. Understand.

Learn what the numbers mean before drawing conclusions.

01

Close-Approach Distance

The predicted separation between an object and Earth at its closest approach. A close pass does not automatically mean an impact will occur.

02

Relative Velocity

The speed of the object relative to Earth during the recorded close approach. Velocity is not an impact probability.

03

Orbital Uncertainty

Orbital predictions depend on observations and the fitted orbit. This dashboard does not calculate a complete uncertainty region or covariance analysis.

04

Hazard Classification

A potentially hazardous classification is based on defined size and orbital criteria. It does not mean that an object is predicted to collide with Earth.

Data Sources & Methodology

Near-Earth object records are requested from NASA's NeoWs API through the Python backend. The dashboard reports the available source measurements and explicitly identifies missing values.

The 3D scene is a visualization aid, not a precision ephemeris. No collision probability is calculated from close-approach distance alone.
